# Environment for the GPU laptop (finetune/ and the caching scripts).
#
# Install PyTorch WITH CUDA first - it is not listed here on purpose, because a plain
# `pip install torch` gives the CPU build:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#
# then:
#
#   pip install -r finetune/requirements-gpu.txt
#
# Never `pip install -r requirements.txt` (the root one) on the GPU laptop: its torch pin
# would replace the CUDA build with a CPU one.
